How to use the Islamic assistant

The Islamic assistant is powered by Claude AI (your own API key) and communicates over Telegram. It answers Islamic questions in real time and sends scheduled briefings at prayer times or Hijri events — no HomeyScript, no Logic variables, no Advanced Flow required for most setups.

▶ Setup checklist

1. Create a Telegram bot — message @BotFather on Telegram → /newbot → copy the token it gives you.

2. Paste the bot token here — Enable & API key → Telegram bot token. The app will start listening for messages automatically.

3. Add your Anthropic key — sign up at console.anthropic.com, create a key (sk-ant-…), paste it in Anthropic API key, and press Validate key.

4. Toggle Enable ON and press Save assistant settings.

5. Find your chat ID — message your new bot anything. The app log shows the sender ID. Copy it into Default Telegram chat ID (for scheduled sends) and optionally into Allowed chats (to restrict replies to known chats only).

6. Message your bot — it should reply within a few seconds. No Flow needed for Q&A.

▶ Q&A — answering messages (no Flow needed)

Once the bot token is set and Enable is ON, the app listens directly — no Flow required. Just message your bot:

Message you send What it does
When is Asr today?Calls get_prayer_data, returns your calculated Asr time
Give me a hadithFetches an authenticated hadith from 7 collections
Dua for anxietyRetrieves the matching Hisn al-Muslim chapter verbatim
Morning adhkarReturns the full morning & evening adhkar block
How many rakats in Dhuhr?Answers from general Islamic knowledge
Quran verse on patienceFetches 2:153 with Arabic + English translation
What is the Hijri date?Calls get_prayer_data, returns today's Hijri date
How long until Maghrib?Calls prayer data + current time, computes the countdown

Rate limit (default 10 s) and daily cap (default 50) apply per sender. Adjust in Behavior.

▶ Scheduled messages — Basic Flow (recommended)

Use the "Islamic Assistant: generate & send" card — it generates the message and sends it via the built-in bot in one step. Requires Default Telegram chat ID to be set above.

WHEN  Prayers Alert → A prayer time has passed
AND   Prayers Alert → Prayer is → Fajr
THEN  Prayers Alert → Islamic Assistant: generate & send
        Preset: Morning briefing
WHEN  Prayers Alert → A prayer time has passed
AND   Prayers Alert → Prayer is → Maghrib
THEN  Prayers Alert → Islamic Assistant: generate & send
        Preset: Evening adhkar reminder
WHEN  Homey → Every day at 07:00
THEN  Prayers Alert → Islamic Assistant: generate & send
        Preset: Daily hadith

Presets available: Morning briefing, Daily hadith, Quran verse, Friday Jumu'ah reminder, Ramadan schedule, Next prayer countdown, Morning & evening adhkar, After-prayer adhkar, Before-sleep adhkar, Travel duas, Evening adhkar reminder. Edit any preset text in the Prompt library above.

▶ Hijri calendar & occasion triggers

Trigger on Islamic events without knowing the Gregorian date:

WHEN  Prayers Alert → A Hijri month event → Ramadan starts
THEN  Prayers Alert → Islamic Assistant: generate & send
        Custom: Ramadan Mubarak! Get today's Suhoor (Fajr) and
                Iftar (Maghrib) times and send a warm greeting.
WHEN  Prayers Alert → An Islamic occasion → Eid al-Fitr
THEN  Prayers Alert → Islamic Assistant: generate & send
        Preset: Islamic occasion greeting

Available occasions: Eid al-Fitr, Eid al-Adha, Arafah, Ashura, Laylah al-Qadr, Mawlid. The Hijri date offset trigger lets you fire X days before/after an occasion.

▶ Advanced Flow — when you need token output

Use "Islamic Assistant: scheduled message" (returns {{assistant_reply}} token) if you need to branch on the reply, send to multiple chats, or chain with other cards:

WHEN  Prayers Alert → A prayer time has passed → Fajr
THEN  Prayers Alert → Islamic Assistant: scheduled message
        Preset: Morning briefing
AND   Logic → {{assistant_reply}} is not empty
THEN  Telegram → Send a message  (To: chat A, Body: {{assistant_reply}})
THEN  Telegram → Send a message  (To: chat B, Body: {{assistant_reply}})

For inbound Q&A via the spkes Telegram app (instead of the built-in listener), use the "Islamic Assistant: reply to a message" card with {{message}} and {{chat id}} tokens piped from the Telegram trigger.
